# 🌸 Nagai Vasantham Decorators - Web Application

![Nagai Vasantham Decorators](our%20works/WhatsApp%20Image%202026-07-04%20at%203.38.18%20PM.jpeg)

Official website for **Nagai Vasantham Decorators**, Nagapattinam's premier wedding, reception, and event decoration service provider **established in 1992**.

---

## 📌 Overview

This project is a modern, responsive, high-aesthetic single-page web application designed for **Nagai Vasantham Decorators**. It showcases portfolio works, detailed service offerings, client reviews, interactive stats, direct contact options, and automated WhatsApp booking integration.

---

## ✨ Features & Highlights

- 👑 **Royal Luxury Design**: Custom color palette (Maroon, Metallic Gold, Ivory Cream, Blush Rose) with responsive mobile-first layouts.
- ✨ **Interactive Particle Canvas**: Canvas-driven falling rose petals and floating gold sparkles.
- ⌨️ **Typewriter Hero Tagline**: Dynamic multi-phrase animated hero section header.
- 🖼️ **Portfolio Gallery with Lightbox**: Categorized image gallery (Weddings, Receptions, Birthdays, Stage & Rentals) with full-screen popup slider navigation.
- 🛋️ **Comprehensive Services**:
  - Wedding & Reception Stage Decor
  - Traditional Temple Flower Arrangements
  - LED & Intelligent Ambient Lighting
  - Organic Balloon Arches & Theme Parties
  - Shamiana & Waterproof Tents
  - Banquet Chairs & Furniture Rental
  - **Jumbo Air Cooler & Mist Fan Rentals**
- 📱 **Automated WhatsApp Booking**: Inquiry form that auto-formats customer details and opens a WhatsApp chat (+91 98653 34050).
- 📞 **Floating Quick CTAs**: One-click WhatsApp and Call buttons for mobile and desktop visitors.
- 📊 **Animated Statistics Counter**: Highlights 34+ Years of Excellence, 500+ Completed Events, and 450+ Happy Families.
